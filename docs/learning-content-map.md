## Resource model

| Resource type | Count represents | Intended destination |

| Notes | Active note documents | Open the selected note reader |
| PDFs | Active PDF resources | Open preview or secure download |
| Past papers | Active examination papers | Open the selected paper/download directly |
| Flashcards | Active flashcard decks | Open the selected deck and its cards |
| Quizzes | Active quiz questions | Start a quiz scoped to the selected curriculum area |
| Active Recall | Active recall questions | Start a recall session scoped to the selected curriculum area |
| Videos | Active video records | Open the selected video player |

The content journey must be resource-aware. Curriculum is the organisation layer; resource type determines the final activity. Do not force PDFs, papers, decks, quizzes and videos through a generic lesson reader.

- O-Level has the broadest examination-paper coverage, but no flashcard decks. Active Recall is currently concentrated in Form 1 Introduction to Biology.
- A-Level has notes, PDFs and quizzes in a limited number of units, but no active past papers, flashcard decks, Active Recall questions or videos.
- Pharmacy has flashcards and quizzes across all ten course units, but no active past papers or Active Recall questions. Flashcard coverage is concentrated in Certificate and Degree; the three Diploma units have none.
- No active video records exist, although the database and application content-link model already recognise videos.
- Empty course units at audit time: Form 2 Transport Systems and Excretion; Form 3 Reproduction and Growth and Development; Form 4 Evolution and Exam Readiness and Revision; Form 5 Biological Molecules; Form 6 Evolutionary Biology, Ecology and Conservation, and Applied Biology.

## Recommended learning progression

The journey should be built around the content that actually exists for the selected course unit. It should not show empty stages or imply that a resource exists when it does not.

1. **Learn:** show the selected note or lesson content. If no note exists, offer the available resource types without presenting an empty reading stage.
2. **Reference:** offer relevant PDFs when available. Open the selected PDF directly in its preview/download experience.
3. **Reinforce:** offer the selected flashcard deck when available. Open the exact deck, not the generic flashcard landing page.
4. **Retrieve:** offer Active Recall when questions exist. Start a session scoped to the unit or selected note.
5. **Apply:** offer a unit-scoped quiz when questions exist. Start the quiz directly.
6. **Examination practice:** offer linked past papers when available. Open the selected paper/download directly.
7. **Watch:** when video records are added, open the selected video player. Videos should appear where pedagogically relevant rather than being forced to the end.

This is a flexible sequence, not a mandatory seven-step checklist. The interface should omit unavailable stages and preserve the learner's course-unit context when moving between resource types.

## Implementation requirements

- Resolve the selected curriculum unit and all active descendants before building related-resource stages.
- Merge direct `unit_id` assignments with `learning_content_links`, deduplicating by resource type and content ID.
- Respect each resource's active and premium state. A premium resource must lead to the subscription flow when access is denied, preserving the intended resource destination.
- Use exact resource identifiers in destinations: note ID, PDF ID, paper ID, deck ID, and scoped quiz/recall unit ID.
- For past papers and PDFs, invoke the existing secure download endpoint rather than exposing storage paths.
- Keep the current learner's programme and curriculum selection through navigation and back-navigation.
- Do not display empty resource categories or placeholder links.
- Do not use aggregate question counts as though they were a single question or deck; display the count and open the correct activity scope.
- Ensure teacher-facing discovery can later use the teacher's approved subject and level, rather than reusing student-only personalisation.

## Audit limitations

This is a point-in-time database inventory. It confirms active records and curriculum assignments, not the academic accuracy, completeness, file integrity, premium configuration, or playback quality of each individual item. Resource-level QA and a separate audit of video administration are still required before claiming the library is complete.
